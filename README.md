# infinite-canvas-muse

一个给 Muse 用的「无限画布工作台」搭建配方仓库，不是能直接 `npm run dev` 跑起来的普通前端项目。

## 这是什么

- 原型：GitHub 项目 [ZhuYichuan/infinite-canvas](https://github.com/ZhuYichuan/infinite-canvas)（MIT，fork 自 basketikun/infinite-canvas），ComfyUI 风格的拖拽节点式无限画布工作台。
- 目标：在 Muse 里重建一个像它的工作台，放在侧边栏当 Space 用。
- 后端：**不接本地 ComfyUI，改走 Muse 的图像和视频生成**。
- 这个仓库里没有可直接运行的 Muse Space 源码 —— Muse Space 是 Muse 打包托管的，代码、保存、生成、Google Drive 都是走 Muse 自己的后端和存储格式，导出来也跑不起来。

## 朋友怎么用（一键配置的正确姿势）

1. `git clone` 这个公开仓库，或者直接把仓库链接发给自己的 Muse。
2. 把 `PROMPT.md` 全文发给自己的 Muse，让它按里面说的建一个 Space，放在侧边栏。
3. 想用自动备份到 Google Drive 的话，先在自己的 Muse 里连接 Google Drive，再在工作台里确认自动备份开关是开着的。

全程大概几分钟，不用装 ComfyUI，不用自己部署。

## 仓库里有什么

- `PROMPT.md` — 直接发给 Muse 的搭建提示词，复制粘贴就能用。
- `SPEC.md` — 详细规格：UI 配色、节点、连线、缩放、拖拽上传、放大查看、Drive 备份等，Muse 搭建时按这个对。

本仓库只有这三个文件，不含画布 workflow JSON、图片 / 视频本体，也不含任何人的 Drive 文件 ID 和链接。图和视频要在自己的工作台里重新生成或重新上传。

## 功能清单（已在原工作台上验证过）

- 多画布切换、新建、删除、重命名（点顶栏标题直接改名，自动保存）
- 无限画布拖拽平移、滚轮缩放 10%–300%、按钮缩放、FIT、小地图、点阵 / 线条 / 空白背景切换
- 节点拖拽、右下角改大小、彩色端口连线；节点：提示词、文生图、图生图、图生视频、生成配置、图片素材、预览、便签
- 双击空白新建节点，底部加节点 Dock，撤销重做，画布 JSON 导入导出
- 从电脑直接拖图片进画布：拖到空白处新建图片节点，拖到图片节点上替换
- 生成走 Muse：图片同步生成落到节点上，视频后台异步生成、好了自动回填
- 点图片 / 视频打开全屏放大查看：滚轮和按钮缩放、放大后拖动平移、左右切换、Esc 关闭；视频带播放 / 暂停、进度条、音量、循环
- 每次生成后自动备份到 Google Drive，默认开，可开关；新生成存到云盘根目录 `muse-盐`，按生成日期分文件夹，老文件不动；节点和素材库显示备份状态和云盘链接，失败可重试
